## 문제 정보

- **대회:** 제2회 영남권 사이버 공격 방어 대회
- **문제명:** What is Love
- **분류:** Bonus / Audio Forensics
- **첨부 파일:** `What_is_Love.zip`
- **플래그 형식:** `FLAG{...}`

## 문제 요약

야구장에서 응원곡을 듣던 중 어떤 악기 하나가 빠진 것 같다는 내용이다. 첨부된 MP3 파일을 분석하여 해당 악기를 찾고, 올바른 플래그를 제출해야 한다.

문제에서 음원의 **분석**을 강조하고 있으므로 단순히 음악을 듣는 것뿐 아니라, 오디오의 파형이나 주파수 성분에 숨겨진 정보가 있는지 확인할 필요가 있다.

## 1. 첨부 파일 확인

ZIP 파일의 압축을 해제하면 다음 MP3 파일을 얻을 수 있다.

```text
what_is_love.mp3
```

파일 정보를 확인한 결과는 다음과 같다.

```text
형식       : MPEG Audio Layer III (MP3)
샘플레이트 : 44.1 kHz
채널       : Mono
비트레이트 : 192 kbps
재생 시간  : 약 14.95초
```

파일 내부 문자열과 메타데이터를 먼저 확인했지만 플래그로 볼 수 있는 평문이나 별도의 첨부 데이터는 발견되지 않았다. 따라서 실제 오디오 신호를 분석해야 한다.

## 2. 스펙트로그램 분석

스펙트로그램은 시간에 따라 각 주파수 성분의 세기가 어떻게 변하는지를 이미지로 나타낸 것이다. 오디오 스테가노그래피 문제에서는 특정 주파수에 신호를 배치하여 문자나 그림을 숨기는 방식이 자주 사용된다.

Audacity를 사용할 경우 다음 과정으로 확인할 수 있다.

1. `what_is_love.mp3`를 Audacity로 연다.
2. 트랙 이름 옆 메뉴를 클릭한다.
3. 파형 표시 방식을 **Spectrogram**으로 변경한다.
4. 필요하다면 스펙트로그램 설정에서 최대 주파수와 대비를 조절한다.
5. 트랙 전체가 보이도록 화면을 축소한다.

명령행 도구를 사용한다면 FFmpeg로도 스펙트로그램을 만들 수 있다.

```bash
ffmpeg -i what_is_love.mp3 \
  -lavfi "showspectrumpic=s=2560x1440:legend=disabled:color=gray" \
  spectrogram.png
```

생성된 스펙트로그램을 확인하면 음원의 주파수 영역에 다음 문자열이 큰 글자로 기록되어 있다.

```text
FLAG{BBU_BU_JELL4}
```

## 3. 문자열 해석

플래그 내부의 `BBU_BU_JELL4`는 한글 발음으로 읽으면 **부부젤라**를 나타낸다. 마지막의 `4`는 흔히 사용하는 리트스피크(leet speak) 표현으로, 알파벳 `A`를 대신한다.

부부젤라(Vuvuzela)는 경기장에서 응원할 때 사용하는 긴 나팔 형태의 악기이다. 문제에서 언급한 야구장과 응원곡도 이 악기를 연상시키는 단서다.

## 플래그

```text
FLAG{BBU_BU_JELL4}
```

## 핵심 포인트

- MP3의 메타데이터나 평문 문자열에는 플래그가 없었다.
- 음원을 스펙트로그램으로 시각화하면 숨겨진 문자가 나타난다.
- 플래그 문자열은 경기장 응원 악기인 **부부젤라**를 의미한다.
